# 별의 심장, 핵융합

**https://infgrp.github.io/stellar-fusion/**

별의 중심에서 수소 네 개가 헬륨 하나가 되는 두 길 — **p-p 연쇄**와 **CNO 순환** — 을
three.js 로 입체적으로 보여 주는 수업용 시각화. `index.html` 하나로 돌아간다 (설치·빌드 없음).

## 흐름

1. **별 전체** — 4분의 1을 잘라 낸 태양 단면. 핵(약 1570만 K) · 복사층 · 대류층을 실제 반지름 비율로, 표면은 쌀알무늬.
2. **핵 속으로** — 카메라가 중심으로 날아 들어가면 열운동하는 플라스마 속에서 반응이 하나씩 펼쳐진다.

| p-p 연쇄 | CNO 순환 |
| --- | --- |
| ① p + p → ²H + e⁺ + νₑ — 쿨롱 장벽, 양자 터널링, 양성자 → 중성자, 양전자 소멸 2γ | ① ¹²C + p → ¹³N + γ |
| ② ²H + p → ³He + γ | ② ¹³N → ¹³C + e⁺ + νₑ (반감기 약 10분) |
| ③ ³He + ³He → ⁴He + 2p | ③ ¹³C + p → ¹⁴N + γ |
| Σ 4.031300 u → 4.002603 u, 0.71% → 26.7 MeV | ④ ¹⁴N + p → ¹⁵O + γ (가장 느린 단계) |
| | ⑤ ¹⁵O → ¹⁵N + e⁺ + νₑ (반감기 약 2분) |
| | ⑥ ¹⁵N + p → ¹²C + ⁴He — 탄소는 촉매 |

- 단계마다 반응식 · 설명 · 캡션, 재생/이전/다음, 속도 0.5× ~ 2× (Space, ←/→)
- 방출 에너지 누계: 빛·열로 남는 몫과 중성미자가 가져가는 몫을 따로 (합계 26.73 MeV)
- 중심 온도 슬라이더: p-p ∝ T⁴, CNO ∝ T²⁰ (1700만 K 에서 같다고 맞춘 근사식) — 어느 쪽이 앞서는지,
  온도에 따라 열운동 속도와 플라스마 색이 바뀐다

## 수업용 직접 링크

| 주소 뒤에 | 효과 |
| --- | --- |
| `?core` | 핵 속에서 바로 시작 |
| `?core&mode=cno` | CNO 순환으로 |
| `&step=4` | 그 단계부터 |
| `&t=5&pause` | 그 단계의 5초에서 멈춘 화면 |

## 고치기

`src/` 의 세 조각을 고친 뒤 합친다.

```
cat src/a_head.html src/b_engine.js src/c_story.js > index.html
```

- `a_head.html` — 화면 구성과 CSS
- `b_engine.js` — 렌더러 · 별 단면 셰이더 · 플라스마 · 핵(Nucleus) · 감마선/중성미자/양전자 효과
- `c_story.js` — 반응 단계 대본(PP, CNO) · 재생기 · 온도 그래프 · 카메라 이동

three.js r128 (cdnjs) 과 examples/js 의 OrbitControls · CSS2DRenderer · UnrealBloomPass (jsDelivr) 를 쓴다.
